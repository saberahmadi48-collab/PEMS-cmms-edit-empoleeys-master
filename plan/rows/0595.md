## Evidence

Owner goal 2026-11-19: adding, removing or editing any form or page needs no code, build or deploy, only the database via the migrator. Code audit found this gap.

## Prompt

These actions ask a security key before running. Make it an action setting instead of controller code.

## Requirement

Done when: A definition declares stepUp; the host runs the challenge and then the operation; denial is audited.

## Report

2026-11-19 (SCRUM-595): an action definition may declare stepUp {resource, action}; ActionExecutor asks IStepUpVerifier (WebAuthn): challenge (ActionStatus.StepUpRequired, HTTP 428 for fetch), verified answer then the operation runs, denial audited, never runs without a verifier. Services that check the WebAuthn answer themselves (Permit close and respond, Isolation verify) are converted in the conversion batches. Browser ceremony check is a QA line.
